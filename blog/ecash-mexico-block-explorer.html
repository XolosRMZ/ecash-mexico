Cómo usar Xolos Explorer:
El Explorador de Bloques Comunitario

Aprende a navegar las transacciones de eCash (XEC), consultar saldos de eTokens y auditar registros de linaje inmutables on-chain.

1. Más allá de un Explorador Técnico

En la infraestructura blockchain tradicional, un explorador de bloques es visto como una simple herramienta de depuración o auditoría de hashes fríos. Sin embargo, alineados con la visión soberana de eCash México, el desarrollo de Xolos Explorer rompe este paradigma.

Construido utilizando el stack moderno de React + Vite y conectado directamente a nuestro endpoint soberano de la Chronik API (https://chronik.xolosarmy.xyz), esta interfaz combina la precisión matemática de la red eCash con las capas narrativas y culturales de nuestro Estado Red. No solo buscamos rastrear transacciones, sino dar visibilidad a la memoria digital viva.

Características Principales de la Herramienta

⚡ Resolución en Milisegundos

Gracias a la indexación directa de Chronik, las consultas de saldos e historiales cargan de forma instantánea.

🐾 Desgranado de Linaje

Módulo exclusivo capaz de interpretar registros nativos estructurados en las salidas de datos del protocolo.

📦 Gestión de eTokens (NFTs)

Fichas integradas con resolución de metadatos IPFS para la visualización directa de colecciones coleccionables.

🔒 Auditoría de Integridad

Comparación automática entre los hashes documentales guardados en la génesis y la metadata real consultada.

2. Anatomía de una Búsqueda Global

La barra de búsqueda de Xolos Explorer implementa un motor de detección inteligente en el frontend. No necesitas indicarle al sistema qué estás buscando; el software analiza el formato del string ingresado y redirige automáticamente a la sección correspondiente:

  • Altura de Bloque: Si ingresas únicamente números (ej: 9000), el explorador te llevará al índice del bloque, desplegando su tamaño, número de transacciones y marca de tiempo.
  • Dirección eCash: Cadenas que comienzan con el prefijo oficial ecash:. Te mostrará el balance visible en XEC, la lista de UTXOs activos y tus coleccionables o tokens fungibles separados de forma lógica.
  • Hashes de 64 caracteres: El sistema resolverá de forma autónoma si el hash corresponde a una transacción (TXID) o a un Token ID específico, mostrándote su árbol genealógico si cumple con los estándares criptográficos del linaje.

3. El Secreto está en el OP_RETURN

Uno de los componentes más avanzados de Xolos Explorer es su capacidad para realizar lo que llamamos arqueología moderna. Cuando interactúas con transacciones del ecosistema, el explorador escanea los scripts de salida en busca de la instrucción de script OP_RETURN (representada por el código hex inicial 6a).

Si el script contiene el prefijo oficial de registro de linaje de xolosArmy, el explorador activa una capa visual de Ficha Oficial de Linaje, traduciendo los bytes crudos a un formulario estructurado legible por cualquier persona:

6a 584f4c4f7c52414d4952455a7c 4e4f4d4252453d54494b417c4e41433d323032352d31302d3036...

Al identificar este formato, el software procesa las variables internas y despliega de manera automática los datos biológicos guardados en piedra digital: nombre completo, afijo de criadero, variedad, sexo, color, número de microchip subdermal verificado y enlaces criptográficos directos hacia las fichas individuales de sus progenitores (padre y madre), construyendo un árbol genealógico dinámico en pantalla.
